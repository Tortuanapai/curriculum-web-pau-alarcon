# Currículum Web — Pau Alarcón

Técnico SMX · Estudiante ASIX 2º — Currículum web estático (HTML + CSS + JS, sin dependencias).

🌐 Web publicada con GitHub Pages: https://tortuanapai.github.io/curriculum-web-pau-alarcon/

## Archivos
- `index.html` — estructura del CV
- `style.css` — estilos dark/light + responsive + print a PDF
- `script.js` — typing, reveal on scroll, tema, menú móvil
- `foto.jpg` — foto profesional

## Ver en local
Abre `index.html` en el navegador, o sirve la carpeta:
```powershell
npx serve .
```

## Despliegue (GitHub Pages)
Repo público, rama `main`, carpeta `/ (root)`.
En Settings → Pages → Deploy from a branch → `main` / `/ (root)`.
